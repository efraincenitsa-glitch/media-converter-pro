Cómo funciona El motor FFmpeg se carga una vez desde CDN y luego procesa cada archivo en memoria, en tu propio navegador. Cierra la pestaña y no queda rastro en ningún servidor.
Esta página se abrió como archivo local (file://)

El motor de conversión usa un Web Worker que los navegadores bloquean fuera de un servidor. Sirve esta carpeta con un servidor local (por ejemplo python3 -m http.server) o súbela a GitHub Pages para poder convertir archivos.
